## 🔎 프로젝트 개요
이 프로젝트는 **HTML, CSS, JavaScript**만을 사용하여 구현된 **프론트엔드 웹 애플리케이션**입니다.
>**선정 이유?**

    그동안 배운 다양한 프론트엔드 기술들을 "커뮤니티 사이트"에 적용하기 좋을 것이라고 예상했습니다.

    1. 로그인 관련 페이지에서 정규표현식을 이용한 유효성 검사 구현
    2. 대학교명,  학과,  강의 정보가 담긴 JSON  데이터를 가져와 페이지에서 응용
    3. 커뮤니티에서 가장 큰 비중을 차지하는 게시판을 로컬 스토리지를 이용해 구현
    4. 주제에 맞는 사이트로 강의평가,  시간표 제작 페이지 등 
    5. 우리 조만의 특색있는 페이지를 만들 수 있을 것이라고 예상


---


⚙️ 주요 기능 소개

| 기능명         | 설명                                       |
| -------------- | ------------------------------------------ |
| 회원 가입 | 정규표현식을 이용한 검증 과정을 넣고, 로컬 스토리지를 활용해 회원 가입 정보를 저장 |
| 내 정보 확인 | 로컬 스토리지에 저장된 정보를 가져와 내 정보 보기 페이지에서 출력|
|로그인|로컬 스토리지에 저장된 회원가입 정보를 통해 아이디와 패스워드가 일치하는지 확인해 로그인 승인/ 거부|
|계정 찾기|로컬 스토리지 활용하여 저장된 정보에 이메일이 있는지 확인한 후 같이 저장된 아이디를 출력|
|공지사항|로그인,  로그아웃,  관리자 권한을 감지해 게시글 작성을 승인/ 거부|
|자유게시판|게시글 작성 시 제목과 내용중 하나라도 공백일 경우 오류 메시지와 함께 로컬 스토리지에 저장되지 않음|
|강의검색|JSON 데이터를 활용하여 검색 기능 구현([공공 데이터 포털](https://www.data.go.kr/)의 대학교 강의명 데이터)|
|강의평가|사용자가 입력한 텍스트와 별점을 로컬 스토리지에 저장, 강의 평가 목록에 출력|
|시간표|사용자가 입력한 정보를 색깔이 있는 블록으로 시각화 하여 시간표에 출력|
|학점계산기|사용자가 입력한 정보를 바탕으로 각 학기의 평균 학점을 계산해 차트로 표현([ApexChart.js](https://apexcharts.com/) 활용)|
